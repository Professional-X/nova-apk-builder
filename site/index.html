🔑 Enter GitHub Token

Paste your GitHub Personal Access Token to connect.

Your token stays in this browser only (sessionStorage). It is never sent anywhere except GitHub's API.

How to create a token (30 seconds)
  1. Open github.com/settings/tokens/new
  2. Set Note to anything (e.g. "APK Builder")
  3. Set Expiration to 30 days
  4. Select repo (full control of private repositories)
  5. Click Generate token
  6. Copy the token and paste it above
